# 查找与阅读定位优化 · 2026-10-10

基线：[b840545](https://github.com/yongqixue99-hue/ai-atlas/commit/b84054578235743428ff9d12eb94f65d0bdea753)。本轮针对实际搜索路径的缺陷，不扩展人物或关系资料。

## 复现的问题

- 搜索 `Green Dot` 没有结果，尽管 Sam Altman 的背景正文已收录收购段落。
- 搜索完整姓名 `Sam Altman`、产品名 `ChatGPT` 或 `GPT-4` 后直接按回车，会进入 OpenAI 公司页。原搜索按数据排列，间接提及排在准确名称之前。
- 搜索 `The Intelligence Age` 找到作者，但只到人物页顶部；事件搜索也只到时间线顶部。
- 产品分类下搜索人物姓名时，提示没有收录，实际上其他分类已有结果。
- 中文输入法的确认键会被当作打开搜索结果；在当前人物页重复选择同一结果后焦点会掉到页面 BODY。

## 改动

- 独立、无依赖的本地检索索引。名称、中文名、别名与文章标题优先；覆盖全部人物背景正文、速览、角色段落与已收录文章。
- 每个人物仍只占一个结果，显示最相关的简短上下文，避免把每个段落变成一排结果。
- 背景命中进入对应章节并展开；精选文章进入具体文章；未列入精选的原文进入引用它的章节。若某位共同作者的正文没有引用该篇文章，则到其资料清单中的准确原文条目。
- 事件定位到对应时间节点。人物目录用 URL 保存当前章节，但不为每次目录点击增加返回步骤；搜索导航仍有独立的前进后退记录。刷新和重复访问保留目标，键盘焦点落到实际内容。
- 修复 WebKit 在整页刷新后覆盖章节滚动位置的问题，在页面显示时恢复目标。
- 分类为空但其他分类有结果时，提供“查看全部分类”，保留原关键词。
- 忽略中文输入法组合期间的回车、方向键与关闭快捷键；修改键点击保留浏览器新标签页行为。
- 非法的章节目标安全回退，不把 URL 参数当作 CSS 选择器或 HTML。
