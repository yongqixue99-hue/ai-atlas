# 减少默认信息：2026-10-07

本轮从实际页面重新检查信息层次，先交付两张低密度参考图，再调整实现。参考图：[首页](AI-Atlas-Concept-Quiet-Home.png)、[关系页](AI-Atlas-Concept-Quiet-Relationships.png)。它们是设计参考，实际交互以网站为准。

## 默认界面只承担一个任务

首页让读者选择探索的公司。标题缩为两行，一句介绍和一个主按钮；右侧用 OpenAI 与产品形成视觉中心。公司索引保留名称、短方向和覆盖范围，人物与专题以简短入口呈现。移除版本横条、栏目编号、重复英文小标题、段落式人物摘要和多层主题说明。

关系页让读者看到连接并选择一个对象。保留人物图和一条选中摘要；不再把状态、类型、机构、列表、日期、来源、图例同时摊开。节点使用头像/文字标识、姓名和简短关系。完整身份、历史限定、精确方向、来源和日期仍在「查看依据」中。

## 渐进展开

- 「浏览设置」包含资料状态、关系类别、浏览中心、视图与重置
- 「查看依据」包含选中对象的独立关系记录、完整日期、证据与原始来源；可收起并恢复焦点
- 「图谱说明」保留一跳关系、资料时效、导航线和非汇报线的解释
- 人物时间线默认收起，完整人物档案仍可独立阅读

浏览设置在连续筛选时保持打开，切换对象或历史导航时清除过期展开状态。来源抽屉与键盘 Escape、返回、重复点击继续验证。

## 约束

没有删除或扩展事实数据。32 条关系、12 位人物、所有来源及其原核验日期均保留。较新记录不是实时目录；历史身份不能因简化文字变成现任。人物作为中心时，机构旁的短关系必须明确关系的主体，避免把个人职位写成机构自己的职位。

排版以一个衬线标题家族和一个正文家族为主，避免每一个提示都另设字阶。手机保留可点击的入口和最多四个邻居，避免单纯把桌面文字缩小。

## 比较方法

使用同一浏览器、1440/390px 宽度记录默认页面的可见正文字符与操作入口；这些数值用于确认确实减少默认内容，不作为审美判断。实际前后截图另存于 `docs/qa/`，最后仍需检查布局、对比度、断行与操作可发现性。
