## 数据约束

保留现有 32 条关系和原核验日期。本轮新增的是表达与浏览方式，不是未经核实的人事事实。

- `current`：原记录明确支持核验时仍成立；并不承诺实时更新
- `historical`：原记录明确标注过去任职、离开或被替代
- `snapshot`：日期限定的任命、职责或协议记录；不自动断言仍在持续，也不表示已经结束
- `event`：产品发布事件
- `navigation`：条目导航，不能当作法律控制边

“较新资料”是 `current` 与 `snapshot` 的阅读筛选，不叫“实时现任名单”。详情仍展示具体证据状态。“联合创始人”是有组织归属的身份标记，不是汇报关系。例如 Mira 的 Thinking Machines 创始身份不能在 OpenAI 节点旁变成无归属的“联合创始人”。

Foundation 与 Group PBC 可作为独立中心。Paul 在前者的董事席位与在后者的无投票权观察员身份必须保持为两条事实。

## 路由、可访问性与手机

根实体、关系类别、资料状态、选中记录和页码由网址恢复。有效旧关系链接可推导实际机构中心；无效参数安全回到有效状态。浏览器前进、后退和刷新均恢复所见内容，重复点击不制造多余历史。

节点与筛选使用真实按钮，档案导航使用链接。重绘后保留合理焦点；来源抽屉支持 Escape、关闭和焦点恢复。手机版不缩小整张桌面图，而是在限定数量的节点后放置所选证据；提供返回节点的操作。动态效果遵守减少动画偏好。
